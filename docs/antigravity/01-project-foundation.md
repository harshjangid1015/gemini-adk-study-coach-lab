# Milestone 1: Project Foundation

## Goals
Initialize the project structure and establish the core Google ADK foundation for the AI Study Coach.

## Deliverables
- Project structure
- `uv` environment and `pyproject.toml`
- Core Pydantic models for student profile and study request
- First Google ADK agent (`study_coach`)
- Environment configuration (`.env.example`)
- Tests and local execution scripts
- Github Actions CI

## Acceptance Criteria
- [x] Pydantic models validate correctly
- [x] Agent is discoverable by Google ADK
- [x] Project passes Ruff, mypy, and pytest checks
- [x] `scripts/run_local.sh` and `scripts/run_tests.sh` execute successfully
